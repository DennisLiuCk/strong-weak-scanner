## 30 秒摘要

- Q2 營收 54.19 億元、年增 16.20%，營業利益 8.36 億元、年增 16.95%；歸母淨利 6.90 億元、年增 84.48%。本業確有成長，但淨利增幅另受匯損縮小、補助與稅負影響，不能全部歸因 AI 或液冷。[S3]（PDF pp.7、32–34）
- 半年營業現金流 6.76 億元，減 PPE 現金 6.93 億元，限定差額負 0.17 億元。液冷出貨與量產排程仍是公司自述，財報未拆液冷收入，不能以合併成長證明新平台已放量。[S3][S4]（S3 PDF pp.9–10、63；S4 PDF p.5）

## 產業位置與競爭格局

建準供應風扇、鼓風扇、馬達、Fan Tray 及散熱模組，範圍延伸至水冷板、水泵、水路分配器及 CDU。這支持風冷與液冷元件能力的延伸，不代表每項產品均有重大收入，也不等於整座資料中心冷卻系統的銷售額。[S1][S4]（S1 PDF p.83；S4 PDF p.4）

年報區分標準品與專案產品：前者競爭信賴性、價格與通路，後者在客戶設計初期協同開發，認證後再競爭量產、品質及成本。此為公司對導入門檻的說明，沒有獨立同業比較或轉換成本量化，不直接認定不可替代。[S1]（PDF p.86）

## 業務與獲利模式

年度業務比重為 DC 風扇、模組及鼓風扇 77.22%，AC 風扇 2.36%，原物料及零組件 20.42%。這是年報管理分類，並非 AI、Server 或液冷各自的毛利分部，不能用其中一類推算液冷占比。[S1][S3]（S1 PDF p.83；S3 PDF pp.62–63）

產品主要售予系統廠及經銷商，在某一時點移轉時認列收入；半年末合約負債 2.63 億元不是全部在手訂單。年度關鍵查核事項為存貨評價及收入認列，研究需分開追蹤備貨、出貨、認列及回款。[S2][S3]（S2 PDF pp.4–5；S3 PDF p.30）

法說列高雄、崑山、北海兩廠、菲律賓巴丹及廣東惠州，惠州定位為液冷／氣冷模組廠，另列建置中的菲律賓第二基地。基地與產品定位是部署，沒有各廠可售產能、利用率或獲利，不能當訂單已滿載。[S4]（PDF p.7）

## 客戶、產品與地區結構

年報表示最近兩年度沒有單一客戶占銷貨達 10%，也沒有單一供應商占進貨達 10%。半年財報採產品、地區及重要客戶期中免揭露，不能推定本季集中度不變，更不能把匿名專案配對特定 CSP 或 ASIC 世代。[S1][S3]（S1 PDF p.93；S3 PDF p.63）

法說 Q1 Server 金額 23.29 億元、AI Server 為 11.11 億元，AI Server 較 2025Q4 的 12.70 億元減少 12.52%。這是管理分類，不能由全公司年增推定 AI Server 季增；占比分母另有下段未調節差異，不直接當合併收入占比。[S4]（PDF pp.20–21、28）

法說 Server 2,329 百萬元標示 47.3%，AI Server 1,111 百萬元標示 22.6%，但同份合併營收為 5,019 百萬元；直接相除約 46.40%、22.14%。核心文件未明列可將金額及百分比調節到合併分母的方法，故保留管理口徑與差異，不稱百分比已獲合併財報驗證，也不猜扣除項目或把差額全歸四捨五入。[S4]（PDF pp.20–21、28）

Q2 大中華部門外部收入 52.60 億元、占合併 97.07%；部門指台灣及中國地區業務，不是中國終端客戶占比。部門損益及銷除加總 9.12 億元對到稅前利益，非營業利益 8.36 億元，不據此算產品營業利益率。[S3]（PDF pp.7、62）

## 財務品質與資本配置

2025 年營收 186.78 億元、年增 27.72%，營業利益 28.09 億元、年增 67.55%，毛利率 31.06%、營業利益率 15.04%；歸母淨利 21.66 億元，基本／稀釋 EPS 報列 7.94／7.93 元。全年 CFO 32.93 億元減 PPE 現金 9.53 億元為 23.40 億元，年度基準不能直接外推半年收現。[S2]（PDF pp.10、13）

以半年減 Q2 還原 Q1，營收 50.19 億元、營業利益 7.88 億元；Q2 分別季增 7.95%、6.05%。但 Q2 毛利率由 Q1 的 31.66% 降至 31.25%，營業利益率由 15.71% 降至 15.43%；金額成長與利潤率小幅下降同時存在，未有產品成本橋接可單獨歸因液冷。[S3]（PDF p.7）

半年營收 104.38 億元、年增 18.27%，營業利益 16.24 億元、年增 32.02%，歸母淨利 13.39 億元、年增 58.24%；基本／稀釋 EPS 報列 4.78／4.77 元。各季加權股數不同，不用半年 EPS 減 Q2 報值代替單季 EPS，亦不把半年增幅當 Q2 增幅。[S3]（PDF pp.7、36）

Q2 淨匯損 13,671 千元，去年同季為 232,840 千元，改善 219,169 千元；補助收入由 4,402 升至 41,017 千元。業外淨額由負 197,835 轉為正 76,393 千元，解釋部分淨利增幅，但不是產品提價或出貨成長，不自製剔除後常態 EPS。[S3]（PDF pp.7、32–33）

Q2 有效稅率 24.37%，稅費含以前年度調整利益 43,231 千元、遞延所得稅利益 101,604 千元，另有未分配盈餘加徵稅額。不同項目共同影響稅後結果，不能只挑稅務利益認定 EPS 全靠一次性收益，也不把單季稅率當全年固定值。[S3]（PDF pp.7、34）

半年 CFO 675,589 千元、年減 43.74%，約為淨利的 50.45%；應收帳款變動占用 539,414 千元、存貨占用 838,590 千元，應付帳款增加釋放 680,164 千元。這是現金流量表調整項，不必然等於兩期餘額直接相減，也不把供應商付款變動全當營運效率改善。[S3]（PDF pp.7、9–10）

半年 PPE 增添 731,042 千元，扣應付設備款增加 38,444 千元，為支付現金 692,598 千元；CFO 減此現金為負 17,009 千元。此限定口徑尚未扣無形資產、租賃本金或股利，不等於完整自由現金流，不將資產增添重複當現金支出。[S3]（PDF pp.10、20）

半年末現金 65.39 億元、較年底增加 12.83 億元；橋接為營業流入 6.76 億元、投資流出 7.85 億元、籌資流入 13.27 億元及匯率影響流入 0.64 億元。籌資含現金增資 16.88 億元及償還長借 7.04 億元，現金增加不能全算本業收現。[S3]（PDF p.10）

六月底應收帳款淨額 56.99 億元、較年底增加 10.55%，存貨 32.60 億元、增加 34.48%；平均授信期兩至四個月。餘額上升不單獨證明需求好壞，應搭配帳齡、信用保險、庫存消化與回款，並區分帳款與含票據的合計應收。[S3]（PDF pp.5、16–17）

六月底流動比率 1.64 倍，低於年底 1.84 倍；銀行短借及長借含流動部分合計 8.91 億元，年底為 11.99 億元，均未含租賃義務。借款下降與現金增加提供緩衝，但流動負債也增加，不能只看現金推定週轉壓力消失。[S3]（PDF pp.5–6）

Q2 存貨回升利益 3,964 千元，另有未分攤製造費用及人工成本 26,375 千元，均反映營業成本。備貨增加與回升利益可並存；應追蹤呆滯、庫齡及製造成本吸收，不把回升利益當新品售價或利用率的直接證明。[S3]（PDF p.17）

## 優勢、弱點與護城河

半年研發支出 6.33 億元、占營收 6.07%，2025 年為 10.82 億元、占 5.79%。持續投入支持產品開發，但支出並非訂單；收入、利潤及回款能否同步成長才是經濟成果驗證。[S2][S3]（S2 PDF p.10；S3 PDF p.7）

年報列高性能對轉風扇、大尺寸 EC 風扇、高功率 In-row CDU、空冷模組及水冷板為開發成果。這是公司技術自述，不能跳過認證、驗收、重複出貨與收入貢獻，亦不能從展示產品推導具名 GPU／ASIC 平台已量產採用。[S1]（PDF p.87）

## 成長動能、催化劑與驗證 KPI

- **液冷里程碑：** 法說稱 Q1 已有水冷板出貨，路線圖列上半年水冷板／液冷模組出貨、CDU 可量產出貨且安規驗證完成，下半年目標為水冷板量產貢獻及客群擴大。已述進度、能力與未來排程須分開；KPI 是驗收、持續出貨、可辨認收入與毛利，不以日期經過認定 Q3 已量產。[S4]（PDF pp.2、5）
- **風冷與 AI 組合：** Server 與 AI Server 歷季金額可追蹤分類變化，但沒有逐 ASIC 世代、具名客戶、不可取消訂單及產品毛利拆解。KPI 是相同分母下的 AI Server 收入、合併利潤及回款，不把產業資本支出或平台功耗直接乘成建準訂單。[S3][S4]（S3 PDF p.63；S4 PDF pp.20–21）

## 風險與預警指標

- **核閱範圍：** Q2 為保留結論，因部分非重要子公司及權益法投資未核閱；相關子公司資產 29.20 億元、負債 9.88 億元，占合併 13.82%、9.31%。這是範圍限制，非已認定錯報；年度查核利用部分其他會計師報告，不可稱全數由同一會計師直接查核。[S2][S3]（S2 PDF pp.4–5；S3 PDF pp.3–4）
- **擴產與備料：** 年報列地緣政治、關稅、工資及削價競爭風險，部分 IC 交期拉長需提高備貨。多地生產與自動化是應對計畫，仍須以庫存、成本及現金檢驗，不把一般備料解讀成 AI 客戶承諾採購。[S1][S3]（S1 PDF pp.90、93；S3 PDF pp.9、17）

## 管理層與治理

現增發行 13,500 千股、每股 125 元，合計現金 1,687,500 千元，目的為償還借款及充實營運資金；六月底普通股 286,944 千股。期末股數、EPS 加權股數與庫藏股口徑不同；資本補充改善現金緩衝但改變每股分母，不以淨利增幅替代每股增幅。[S3]（PDF pp.10、26、36）

本輪核心法說為 IR 清單定位的六月二日 Q1 營運報告，封面及財務仍屬 Q1，不當 Q2 法說。年度查核日三月五日、Q2 核閱日八月七日與列表上傳日期分開保存；核心包未納逐字稿與市場共識，不判斷超預期，也不把展望改寫為已實現結果。[S2][S3][S4]（S2 PDF p.7；S3 PDF p.4；S4 PDF pp.1–2、28）

## 未決衝突

Q2 基本 EPS 在損益表與附註均報列 2.42 元，但分子 690,102 千元除以加權股數 286,040 千股為 2.41261 元，按兩位小數為 2.41 元；稀釋分母 286,215 千股則可重算報列 2.41 元。本文並列原報值與算式，不自行訂正或稱差異已解決；半年報值 4.78／4.77 元可由各自分母重現。[S3]（PDF pp.7、36）
