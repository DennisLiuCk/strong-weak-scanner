# 短週期策略實驗室

這個專案以實驗與理解市場為目的，不用於真實交易。**現在就能開始比較、刪減與修改
實驗候選，不必等到 2027 年 3–4 月。**正式策略的長期驗證仍可累積，但不是實驗迭代的
前置門檻。實驗結果的用途是安排下一輪研究，不是宣稱已找到可交易優勢。

入口：[互動比較報告](reports/experiment_lab.html)、[完整日序列](reports/experiment_lab.json)、
[獨立計算核對](reports/experiment_lab_acceptance.json)。
實驗旋鈕集中在 `config/experiment_lab.json`；正式 `score.py` 權重、tier 與 cutoff 不因
增刪實驗候選而變動。

## 1. 五種快速驗證方式

| 方法 | 何時有回饋 | 能回答什麼 | 允許的動作 |
|---|---|---|---|
| 歷史重播 | 現在，單次約數十秒，依機器而異 | 簡化指標是否改變排名？效果是否只出現在一段？ | 選下一輪的研究方向、移除重複設計；標示探索 |
| 舊正式快照重播 | 現在 | 使用當時凍結的輸入，方向是否仍相近？ | 查現行資料修訂／母體的敏感度；不稱為新策略 OOS |
| 時間分段走動驗證 | 現在 | 前段選出的候選在後段是否崩壞？ | 優先重設不穩定機制；全數候選及失敗區段都保留 |
| 1／3／5 日短窗前瞻 | 首份訊號後 2／4／6 個後續交易日 | 名單能否辨識短期相對強弱？ | 5／10／20 個成熟日固定檢視，快速續測或改版 |
| 族群移除、所有不重疊起點、固定置換 | 現在，以及每次更新 | 是否依賴單一族群、起點或任意的分數配對？ | 把脆弱候選降為次要，保留測試紀錄 |

3 日是主要視窗；1／5 日是敏感度，不能事後挑最好看的視窗。短窗改變了研究問題，
不會憑空增加市場獨立歷史，也不能替代 10 日策略的長期證據。

## 2. 當前七個版本：反轉的效果與名單穩定度

所有版本都用同族群、同股票、同日期與同目標報酬配對。正式元素綜合分 round2，
再採 3 日平均並 round2。BASE 必須逐列與正式 scorer 的 `composite_s` 相等。
本輪比較基準是 **REV1**；BASE、MOM20、NO_VOL 保留作對照，不参加反轉候選選拔。

| ID | 策略 | 改動／新增的問題 |
|---|---|---|
| BASE | 現行綜合分 | 對照組，保留既有六個計分元素；本實驗不套 tier 進出 |
| MOM20 | 純價格動能 | 只留 `s_price`；比較是否值得保留其他元素 |
| NO_VOL | 移除量能 | 將量能權重移除，對應 C1；測量能是否只適合當警示 |
| REV1 | 短線反轉 | `-rank(ret1)`，當日使用；測跌深的短期回補 |
| REV1_S2 | 反轉兩日平滑 | `-rank(ret1)` 的兩日平均 |
| REV1_TREND25 | 反轉搭配 25% 趨勢 | `0.75*(-rank(ret1))+0.25*rank(rs20)` |
| REV1_S2_TREND25 | 趨勢搭配且兩日平滑 | 上述混合分數再取兩日平均 |

反轉家族用連續平均秩線性映射到 −1～+1，先混合、再平滑、最後 round2。
這是兩個機制的完整 2×2 組合，不新增資料來源或搜索更多權重。先前候選與程式完整保留在
`reports/experiment_rounds/fast-lab-v1-20261009/`；停測不代表證明無效。

本輪事先固定的探索取捨：相對 REV1，**平均 IC 損失不超過 0.02、候選 IC 為正、名單
變動至少降低 0.10**。這是平均值的實用容忍度，**不是統計上的非劣性檢定**。
兩種歷史重播各至少 20 個共同成熟日，且都達條件，才優先續測；多個符合者取歷史重播
共同樣本 ΔIC 較高者，平手按登錄順序。兩種重播重疊，不能算兩份獨立證據。
沒有候選符合就保留 REV1。結果與實際研究配置顯示在報告的「本輪實際調整」。

## 3. 可比較的計算口徑

- 訊號日 d，`open(d+1) → open(d+1+H)`；以當前還原因子調整開盤價。
  同一把尺用於候選、REV1 與族群基準。最新還原價可能修訂，不能聲稱重建過去資料版本。
- 先逐族群算 Spearman IC，再每日等權平均族群；主要比較 `IC(candidate)-IC(REV1)`。
  任一腿或目標零變異，整個配對排除；不先各算不同母體的均值再相減。
- 所有候選共用必要欄位完整且已有 3 個連續市場交易日有效輸入的股票。
  原始因子排名仍用當日原族群，完整性限制施加在比較母體。缺失／停牌／缺快照後須重新
  累積 3 日；這比正式 scorer 在有效交易日接續的規則嚴格，會減少覆蓋。
  每組至少 6 檔；任何一檔缺進／出開盤價，整組排除，不用知道結果後縮小股票集合再选尾端。
  仍須注意「被排除的事件可能有資訊」；排除數必須一起閱讀。
- 前／後四分位依平均名次門檻切分。同分跨界一併纳入或排除，不用股票代碼硬湊人數。
  前四分位減後四分位報酬是排序診斷；前四分位減全組等權毛報酬再減 0.585pp 是成本敏感度。
  兩者都是重疊 cohort，不是實際資金投組，不模擬正式 tier、限價成交、換手、滑價或容量。
  本專案不實盤，成本保留作理解用途，不阻擋實驗迭代。
- 每列附日數、日曆區段、n/H、HAC SE/t；n/H 是啟發式尺度，不是量得的獨立樣本。
  主帶寬 H−1，另列至少 5／10 日的持續性敏感度；n/H<3 時不報 SE/t。
  帶寬敏感度樣本不足也顯示空值，不因 F1 就當成 iid。
- 不等結果的結構表另列同分比例、與 REV1 前四分位名單的 Jaccard 相似度、相鄰市場日
  名單 Jaccard 距離，先逐組再逐日等權聚合並附跨日 SE。缺日不相接；名單距離不是資金換手率。
- 決策表只用 IC 與雙邊名單變動皆有效的同族群／同日期格；先逐格算
  `reference_list_change-candidate_list_change`，再日均；正值表示候選較穩定。
  `joint_delta_ic`、`joint_ic`、`list_change_reduction` 共用這些格。
  不拿兩張表不同樣本的平均值相減；結構可用但報酬未成熟者只留在結構表。
- 歷史重播先去除 60 個市場日暖機，使用現行 universe，因此帶有存活、分組、修訂及設計選擇偏誤。
  舊快照只採首次正式且及時版本；用新策略重播它們仍是探索，不能冒充事前登錄的成果。

## 4. 時間分段與壓力測試

走動驗證以 30 個訊號日作起始訓練，採擴展窗口；隔開 6 个交易日後，評估接下來 15 日。
所有訓練標籤必須在測試首日之前結束。只在反轉家族中選擇；候選須有至少 30 個共同訓練日，
達到 §2 的效果／穩定度取捨，再以訓練 ΔIC 選一個版本；沒有合格候選就用 REV1。
測試段的 IC 和穩定度不參加當段選拔，全部候選後段結果都保留。
不足完整 15 日的尾段不建立 fold。
這是歷史上重播一個選擇流程，策略家族本身已參考歷史設計，不能宣稱真正未見資料的驗證。

每個候選另外列出移除每一個族群的 ΔIC ±SE，和 H 個不重疊起點的全部結果；不能只挑最好的
族群刪除或起點。置換對照使用 16 個固定 seed，在族群內以固定 ticker 對映重新分配整條分數路徑；
保留部分時間依賴，缺成員的組日跳過。它是負向控制，沒有交換性或多重檢定保證，不提供 p 值。

設計參考：[時間順序及 gap 的交叉驗證說明](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)
（本專案以 stdlib 實作，沒有引入 sklearn）；
[Bailey 等人的回測過度配適研究](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)
說明嘗試大量策略後只呈現最佳回測的問題。這裡因此固定小型候選集合、保留全部結果，沒有宣稱計算了 PBO。

## 5. 前瞻短循環：可以做決定，不必等半年

以本輪 3 日主視窗為準，首 N 個有效成熟配對日為固定樣本，不因每週重看而新增一次成功。

| 節點 | 最快需要的完整市場日數（含首個訊號日） | 實驗動作 |
|---|---:|---|
| 5 個成熟日 | 9 日，約 2 週 | 核對程式、覆蓋、名單差異；沒有 SE 時明示，不判勝負 |
| 10 個成熟日 | 14 日，約 3 週 | 若 ΔIC ≤−0.05，優先重設或停止此候選；其他可簡化或續測 |
| 20 個共同成熟日 | 至少 24 日，約 5 週 | 整段與首／後 10 日各自達 §2 的效果／穩定度取捨，保留續測；其餘延伸、換機制或另開 round |

這些是**研究時間分配的實用門檻**，容許實驗犯錯，沒有校準顯著性或保證誤判率。
「保留」只代表值得下一輪測試；「停止」也不代表科學上證明無效。區段相鄰而非獨立，
每檔候選的成熟進度可能因缺值／零變異而不同。名單變動另外需要相鄰的合格訊號日，
暖機、缺口恢復或首次前瞻日也可能增加等待。實際日程依交易日與可用資料，不承諾日曆日期。
不需等正式 F10 的 100／200／300 日節點才增刪下一輪的實驗候選。

前瞻只採登錄日期及時間之後、`oos_eligible=true` 的首次正式快照。後來修正版不可取代首次
延遲或不完整的快照。登錄時保存 config、計算及依賴 source SHA；改 evaluator 或依賴後，
須新 round，不能繼續沿用舊前瞻標籤。5／10／20 日檢視以 UTF-8/LF append-only 保存
first-N 日序列、配對格、快照 ID／實際輸入 hash、完整交易日曆及規格；回補、修價或竄改
造成差異即標紅，保留原結果。共同 IC 與名單降低量一起凍結，不能以日後新增資料改寫首 N 日判斷。

## 6. 執行與下一輪

```text
python scripts/experiment_lab.py
python scripts/audit_experiment_lab.py
python -m unittest tests.test_experiment_lab tests.test_experiment_round2
```

兩個分析工具均使用 `db_ro.connect()`，核對 DB SHA 前後一致；輸出只寫報告與實驗檢視帳本。
`weekly-validate` 的既有週六流程會更新實驗報告並核對數值；也可隨時手動執行上述命令。
舊正式策略的長期週報繼續保留。資料表與 HTML archive 不會為這個實驗重算或回填。

新一輪：先保留本輪 config／registry／報告及帳本，修改 `config/experiment_lab.json` 的
`protocol` 為新 ID，再改最多 1～2 個研究機制；執行
`python scripts/experiment_lab.py --register`。工具以執行當下的台灣時間登錄，不接受倒填時間，
已有 ID 不可覆寫。再執行分析與核對命令。生成的 registry 必須與程式及 config 一起保留。
封存還要保存計算原始碼與每檔 SHA；`experiment_rounds/.gitattributes` 保留原始位元組，
避免 Windows／Linux 換行轉換造成假竄改。開發預覽只用於偵錯與探索，正式登錄時間仍採完成時刻。

完整測試使用 Windows 系統 Python 3.12 預設環境；若改實驗計算，補對應的獨立例題／前綴
不變性／缺值／同分／版本／帳本測試。`audit_experiment_lab.py` 共用納入母體與正式 BASE scorer，
獨立重算連續平均秩／混合／平滑、全部候選及視窗的還原開盤報酬、平均秩、日均、cohort、
成對名單降低量與日曆 HAC；它是數值核對，
不把同一份市場資料算兩次當成兩份證據。
